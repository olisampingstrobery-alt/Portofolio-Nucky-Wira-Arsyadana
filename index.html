Tentang Saya

Mengenal Saya Lebih Dekat

Halo! Saya Nucky Wira Arsyadana, siswa kelas XII jurusan Pengembangan Perangkat Lunak dan Gim (PPLG).

Saya memiliki minat besar dalam bidang teknologi, khususnya pengembangan aplikasi dan website. Saya mampu mengembangkan website dari sisi frontend maupun backend menggunakan HTML, CSS, JavaScript, Laravel, React, dan MySQL.

Selain sebagai Web Developer, saya juga memiliki pengalaman sebagai Quality Assurance (QA) dalam project yang saya kerjakan bersama tim. Saya terbiasa menguji fitur, menemukan bug, melaporkan masalah, serta melakukan retesting.

Di sekolah, saya tergabung dalam Unit Produksi PPLG. Pengalaman tersebut membantu saya memahami kerja tim, kebutuhan pengguna, pengembangan aplikasi, dan proses pengujian software secara lebih nyata.
